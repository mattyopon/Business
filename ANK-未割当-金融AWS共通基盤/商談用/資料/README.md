# 商談用資料フォルダ

本フォルダは、商談で利用する PDF・画像ファイルおよび内部作業用プロンプトを格納するためのディレクトリである。

## ファイル一覧

| ファイル名 | 内容 | git 管理 |
|-----------|------|---------|
| GenSpark_プロンプト.md | GenSpark への資料化依頼用プロンプト集（内部作業用） | 対象外（.gitignore） |
| 提案資料.pdf | システム提案資料（生成予定） | 対象 |
| 全体構成図.png | マルチアカウント構成図（生成予定） | 対象 |
| セキュリティ構成図.png | セキュリティ多層防御図（生成予定） | 対象 |

## ファイル生成プロセス

1. 商談用の各テキスト資料（ヒアリングシート、想定 Q&A、技術用語解説、参画前確認チェックリスト、リスクレジスタ等）を確定する。
2. 内部作業用プロンプト（GenSpark_プロンプト.md）を確認する。
3. GenSpark に上記プロンプトを投入し、提案資料・構成図を生成する。
4. 生成された PDF・画像ファイルを本フォルダに配置する。

## 注意事項

- 機密情報（クライアント社名、システム名、IP レンジ等の具体値）は記載しない。
- 公式文書調の中立的な表現を用いる。
- AWS 公式アイコン・公式カラーを使用する。
