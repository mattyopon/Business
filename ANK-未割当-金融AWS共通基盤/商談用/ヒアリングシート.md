# ヒアリングシート - 金融機関 AWS クラウド共通基盤案件

商談および面談時に確認することが望ましい事項を整理したシートである。本案件は金融機関における AWS クラウド共通基盤の要件定義および基本設計を主たる対象としており、技術領域が多岐にわたるため、優先度の高い項目から順に確認することを想定している。
