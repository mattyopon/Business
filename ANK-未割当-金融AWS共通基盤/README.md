## 案件サマリ

金融業界クライアントにおいて、次期中期計画でクラウド利活用を大幅に推進する方針が示されている。
社内の相当数のシステムを複数年で AWS リフトする前提のもと、横展開可能なクラウド共通基盤を整備するプロジェクト。
本案件はその共通基盤の **要件定義および基本設計フェーズ** を支援する。

### 想定スコープ
- AWS 利用システム向けに提供する共通機能の要件整理
- 基盤構成検討（マルチアカウント／ネットワーク／IAM／セキュリティ／運用／IaC／CI/CD／監視）
- 実現方式検討
- 後続フェーズ（基本設計／詳細設計／構築／テスト／本番移行／利用者向け準備）への引き継ぎ資料整備

## 作業内容

### 主な作業
- AWS マルチアカウント構成（Organizations / Control Tower / LZA）の要件整理・基本設計
- VPC / Transit Gateway / Direct Connect / Network Firewall によるネットワーク基盤の設計
- IAM Identity Center を中心としたアイデンティティ・権限統制の設計
- セキュリティサービス（GuardDuty / SecurityHub / Config / CloudTrail / Macie / Inspector 等）の委任設計
- IaC（Terraform / CloudFormation / CDK）方針策定と静的解析・承認ゲート設計
- CI/CD パイプライン（GitHub Actions / CodePipeline 等）と承認運用の設計
- 監視・ログ基盤（CloudWatch / Logs Insights / OpenSearch / 監査ログ長期保管）の設計
- FISC 安全対策基準・金融庁ガイドラインなど金融規制への対応マッピング
- 利用者向けセルフサービス（アカウント発行・ガードレール）の要件整理

### 環境
- AWS（マルチアカウント / マルチリージョン想定）
- Terraform（IaC）
- GitHub / GitHub Actions
- 既存オンプレ AD / Entra ID（連携想定）
- JIRA / Confluence / Slack 等の標準ツール

## 要求スキル

### 【必要】
- AWS 主要サービス（EC2, VPC, IAM, S3, RDS, CloudWatch 等）の理解と運用経験
- ネットワーク設計の基礎（サブネット, ルーティング, セキュリティグループ）
- 非機能要件整理経験（可用性 / セキュリティ / パフォーマンス / スケーラビリティ / バックアップ）
- AWS における要件定義・基本設計・詳細設計・構築の経験
- AWS マルチアカウント設計経験
- VPC / NW アーキテクチャ設計経験
- IAM / セキュリティ設計経験
- セキュリティサービス設計経験
- CI/CD 構築経験
- 監視 / 運用設計経験
- IaC 設計 / 実装経験
- 関係者との連携・コミュニケーション能力

### 【尚可】
- 金融機関（銀行 / 損保 / 生保 / 証券 / カード等）向けシステム経験
- FISC 安全対策基準 / 金融庁ガイドラインへの対応経験
- AWS Landing Zone Accelerator (LZA) / Control Tower 導入経験
- 大規模なクラウドリフト案件における共通基盤側の経験
