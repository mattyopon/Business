# 10-6. 次期クラウド共通基盤 (PF) 連携要件確認リスト

**目的**: PF 側 (オープン勘定系プラットフォーム相当) との連携要件をチェックリスト化し、ガイドライン受領後の差分確認を機械的に行う。  
**運用**: PF 側との週次同期会議で本リストを使い、受領済 / 未受領 / 影響分析中 を可視化する。

---

## 1. PF 側との関係 (案件ポジション)

- 本案件は PF 側の **利用者 (テナント)** として配置される
- PF 側は **共通基盤本体** を提供 (アカウント発行 / NW 接続 / 認証認可 / 監視ログ集約 / セキュリティサービス / コンプライアンス 等)
- 本案件は PF 側のガイドラインに準拠し、その上で **クーポン管理アプリケーション基盤** を構築する

## 4. PF 側との週次同期会議で確認するチェックリスト

### 4.1 毎週確認
- [ ] 受領済ガイドラインの差分有無 (PF 側からの追加 / 変更通知)
- [ ] 影響分析中の項目の進捗
- [ ] 顧客合意待ちの項目の進捗
- [ ] 未受領ガイドラインの次回提供予定
- [ ] PF 側 PoC 結果のフィードバック

### 4.2 月次確認
- [ ] ガイドライン受領率 (全 14 件中 N 件受領済)
- [ ] 影響分析完了率
- [ ] 顧客合意完了率
- [ ] 期限超過項目

## 5. ガイドライン受領 → 適用までのフロー

```
[PF 側からガイドライン受領]
      ↓
[受領日 + 0 日] 内容ざっと確認、Owner アサイン (PM + SA)
      ↓
[受領日 + 3-7 日] 影響分析 (案件側既存設計との差分)
      ↓
[受領日 + 14 日] 影響分析結果を顧客に提示
      ↓
[受領日 + 21 日] 顧客 (主担当 + IT 統括) と協議
      ↓
[受領日 + 28 日] 顧客合意 → 要件 / 設計に反映
      ↓
[Decision Log に転記] [マスタープラン更新] [リスクレジスタ更新]
```
