# 資料ディレクトリ

商談時の補助資料・スライド・図解の格納先。

## ファイル一覧 (予定)

| ファイル | 用途 |
|---|---|
| GenSpark_プロンプト.md | **gitignore 対象**。GenSpark Deep Research に渡すプロンプト集 (内部作業用) |
| 提案資料.pptx | 商談用 PowerPoint (要作成) |
| システム構成図.png | AWS 構成図 (要作成、GenSpark or draw.io) |
| セキュリティ構成図.png | 多層防御図 (要作成) |
| CI-CDパイプライン図.png | CI/CD フロー図 (要作成) |

- GenSpark プロンプトで各図のドラフトを生成

- AWS 公式アイコン使用 (https://aws.amazon.com/jp/architecture/icons/)
