# 参画前確認チェックリスト

**目的**: 契約締結前に必ず確認すべき項目を一覧化。これらが曖昧なまま契約すると参画後に苦労する。

---

## 1. 契約・商務

- [ ] 契約形態 (準委任 / 派遣 / SES) の確認
- [ ] 月稼働下限 / 上限 (160h / 200h 想定)
- [ ] 契約期間 + 更新条件
- [ ] 単価 / 月額
- [ ] 超過稼働の取り扱い
- [ ] 出社地 + 出社頻度
- [ ] テレワーク条件
- [ ] 端末払い出しタイミング (要出社期間)
- [ ] 顧客直接交渉ルール (3 分類)
- [ ] 補強要員の追加調達ルート
- [ ] 案件途中での体制変更可否

## 2. 体制

- [ ] PM (自分) の役割範囲 (PM 兼 SA / PM のみ)
- [ ] 現在の体制 (PM 1 名在籍) との重複・引き継ぎ
- [ ] SA / IaC / QA / 運用の参画タイミング
- [ ] 元請 PL の関与レベル
- [ ] 顧客側責任者・主担当の確定状況

## 3. スコープ

- [ ] 構築フェーズの範囲 (要件定義〜総合テスト全 9 工程)
- [ ] Cutover 後の Hyper Care 期間 (90 日想定)
- [ ] 長期運用保守の別契約可能性
- [ ] Out of Scope の明確化 (親システム改修なし、PF 本体構築なし等)

## 4. 技術前提

- [ ] AWS 利用前提 + リージョン (Tokyo / Osaka)
- [ ] PF 側 PoC スケジュール + ガイドライン提供タイミング
- [ ] 親システム I/F 仕様の現状
- [ ] 想定 AWS サービス (案件概要原文の通り)
- [ ] IaC は Terraform で確定か
- [ ] CI/CD ツールの確定状況

## 5. 規制対応

- [ ] FISC 第 11 版対応の現状
- [ ] 金融庁ガイドライン適用範囲
- [ ] 個人情報保護法対応方針
- [ ] PCI DSS 適用判定
- [ ] 監査部門との関係

## 6. リスク

- [ ] [リスクレジスタ](リスクレジスタ.md) TOP 10 への顧客側認識
- [ ] R-04 (要員不足) への補強要員調達合意
- [ ] R-06 (PM 稼働超過) への対応合意

## 7. 自分自身の準備

- [ ] AWS 認定 (SAP / Security Specialty) 取得状況
- [ ] FISC 第 11 版書籍購入 (要なら経費申請)
- [ ] AWS FISC リファレンス第 2 版精読
- [ ] Terraform v1.10 + AWS Provider v5.100 のセットアップ
- [ ] 既存ANK 巻き取り準備資産の精読 (構造参考)
- [ ] 業務理解 (販促 / クーポン / グループ顧客戦略)

## 8. 契約締結前の最終確認

- [ ] 全項目クリアまたは「持ち越し合意」状態
- [ ] 元請 PL の最終確認
- [ ] 自社マネージャの承認
- [ ] 契約書類の確認 (法務含む)
