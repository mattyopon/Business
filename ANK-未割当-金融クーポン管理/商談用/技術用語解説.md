# 技術用語解説 — 本案件で頻出する技術用語

**目的**: 商談・要件定義時に出てくる技術用語を簡潔に整理する。  
**読者**: PM (自分) 確認用 + 顧客 / 元請への説明補助。

---

## A. 業務系用語

| 用語 | 解説 |
|---|---|
| **特別金利電子クーポン** | 顧客がグループ内取引を行う際に金利優遇を受けられる電子クーポン |
| **全店名寄せシステム / 顧客名寄せ親システム** | 顧客 ID をグループ各社共通で管理するマスタシステム |
| **オープン勘定系プラットフォーム / 次期クラウド共通基盤** | 銀行勘定系の AWS ベース次期共通基盤 |
| **グループ顧客化** | 顧客にグループ内サービスを横断利用してもらう戦略 |
| **PF (Platform)** | 共通基盤の略 |

---

## B. AWS サービス系用語

### B.1 コンピュート / コンテナ

| 用語 | 解説 |
|---|---|
| **VPC** | 仮想プライベートクラウド。AWS 内の独立した仮想 NW |
| **EC2** | 仮想マシン。本案件では限定的利用想定 |
| **ECS** | コンテナオーケストレーション。Fargate (サーバレス) / EC2 launch type |
| **Fargate** | サーバレスでコンテナを実行する ECS のモード |
| **EFS** | NFS 互換の共有ファイルシステム |

### B.2 データベース

| 用語 | 解説 |
|---|---|
| **Aurora** | AWS のフルマネージド RDB (MySQL / PostgreSQL 互換) |
| **Multi-AZ** | 複数 AZ に冗長配置して可用性を高める |
| **RDS Proxy** | DB 接続プール管理 + Failover 安定化 |
| **Point-in-Time Recovery** | 任意の時点に DB を復元する機能 (Aurora は最大 35 日) |
| **Global Database** | 複数リージョン間で DB を複製する Aurora 機能 |

### B.3 ストレージ

| 用語 | 解説 |
|---|---|
| **S3** | オブジェクトストレージ |
| **Object Lock** | S3 オブジェクトの削除/変更を一定期間禁止する機能 (COMPLIANCE / GOVERNANCE モード) |
| **Lifecycle** | S3 オブジェクトの自動アーカイブ / 削除設定 |
| **Glacier / Deep Archive** | S3 の長期保管用 Storage Class |

### B.4 ネットワーク

| 用語 | 解説 |
|---|---|
| **Subnet** | VPC を分割した小さな NW |
| **ALB** | Application Load Balancer (HTTP/HTTPS) |
| **NLB** | Network Load Balancer (TCP/UDP) |
| **TGW** | Transit Gateway. 複数 VPC を中央 HUB で接続 |
| **NAT GW** | Private Subnet からの Egress 用 NAT |
| **Direct Connect (DX)** | オンプレと AWS を専用線で接続 |
| **WAF** | Web Application Firewall |
| **Route 53** | DNS サービス |
| **VPC Endpoint (Interface / Gateway)** | AWS サービスに Private 接続する仕組み |

### B.5 認証認可

| 用語 | 解説 |
|---|---|
| **IAM** | Identity and Access Management |
| **IAM Role** | 一時的な認証情報を付与する仕組み (アクセスキー不要) |
| **IAM Identity Center (旧 SSO)** | AWS マルチアカウントの SSO |
| **Permission Set** | Identity Center のロール定義 |
| **OIDC** | OpenID Connect。GitHub Actions などから IAM Role を assume する |
| **Break Glass** | 緊急時のみ使う高権限アカウント |

### B.6 セキュリティ

| 用語 | 解説 |
|---|---|
| **KMS** | Key Management Service。暗号鍵管理 |
| **CMK (Customer Managed Key)** | 顧客が管理する KMS 鍵 |
| **Secrets Manager** | 機密情報管理 + 自動 Rotation |
| **GuardDuty** | 脅威検知 |
| **Security Hub** | コンプライアンス集約 |
| **Config** | リソース設定変更追跡 |
| **CloudTrail** | API 呼び出しログ |
| **Macie** | 機微データ検知 |
| **Inspector** | 脆弱性スキャン |

### B.7 監視運用

| 用語 | 解説 |
|---|---|
| **CloudWatch Metrics / Logs / Alarm / Dashboard** | 監視・ログの中核 |
| **CloudWatch Anomaly Detection** | 機械学習ベースの異常検知 |
| **CloudWatch Composite Alarm** | 複数 Alarm の AND/OR 評価 |
| **X-Ray** | 分散トレース |
| **Change Calendar (SSM)** | 変更可能期間管理。OPEN / CLOSED 状態 |
| **AWS Backup** | 統合バックアップ管理 |
| **Cost Anomaly Detection** | コスト異常検知 |

### B.8 IaC / CI/CD

| 用語 | 解説 |
|---|---|
| **Terraform** | HashiCorp の IaC ツール (本案件第一選択) |
| **CloudFormation (CFn)** | AWS ネイティブ IaC |
| **LZA (Landing Zone Accelerator)** | AWS マルチアカウント基盤のテンプレ |
| **Control Tower** | AWS マルチアカウント管理サービス |
| **AFT (Account Factory for Terraform)** | LZA と Terraform 連携の仕組み |
| **CodePipeline / CodeBuild** | AWS のネイティブ CI/CD |
| **GitHub Actions / GitLab CI / Jenkins** | 案件で利用候補 (PF 側決定待ち) |
| **tflint / tfsec / Checkov** | Terraform 静的解析ツール |

### B.9 規制対応

| 用語 | 解説 |
|---|---|
| **FISC 安全対策基準 第 11 版** | 金融情報システム向け安全基準 (2023/3 発行、現行最新) |
| **AWS FISC リファレンス第 2 版** | AWS 公式の FISC 対応参考文書 (2024/8 公開) |
| **金融庁監督指針 / サイバーセキュリティガイドライン** | 金融庁の規制 |
| **個人情報保護法** | 個人情報の取り扱いに関する法律 |
| **PCI DSS v4.0.1** | クレジットカードデータ取扱いの国際基準 (2026/4 時点で唯一有効版) |
