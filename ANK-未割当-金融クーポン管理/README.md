# ANK-未割当-金融クーポン管理 (PM 参画準備パッケージ)

**案件**: 大手金融機関グループ向け 特別金利電子クーポン管理子システム (以降「本システム」) を **オンプレ → AWS にリフトアンドシフト** する。要件定義〜総合テストまでの構築フェーズ一気通貫担当。  
**担当**: PM (兼 SA / コンサル相当) として、既存システム現状調査・パラメータ確定・Terraform/自動化による構築まで導く。  
**位置付け**: 親システム「顧客名寄せ親システム (全店名寄せ相当)」の子プロジェクト。既存オンプレコンテナ基盤から **次期クラウド共通基盤 (オープン勘定系 PF 相当、AWS) 配下** へ移行。  
**システム特性**: **完全プライベート業務系** (インターネット公開なし、利用者は行員、顧客は別チャネル経由)。**作業環境は VPN / 閉域網 + 顧客貸与端末** 経由のみ。**行内独自セキュリティ統制多数**。  
**参画予定**: 2026 年 6 月 〜 2028 年 3 月 (構築フェーズ 22 ヶ月)、最大 4 名体制。**PM として大手金融機関案件は初参画**。

> [!IMPORTANT]
> **本リポジトリの位置付け**: フル情報を **Business private リポジトリ** に保管 (`mattyopon/Business`)。第三者への公開・配布が必要な場合のみ別途匿名化版を作成する。

## 出典・引用ルール (ハルシネーション禁止)

本パッケージは金融機関規制対応資料として使用するため、以下の引用ルールを厳守する:

1. **AWS サービス仕様**: AWS 公式ドキュメント (docs.aws.amazon.com / aws.amazon.com/jp/blogs) を一次ソース。記述末尾に URL 必須
2. **FISC 安全対策基準**: FISC 公式 (fisc.or.jp) と AWS 公式リファレンス (d1.awsstatic.com/whitepapers/jp/security/AWS_FISC_Reference_Part_*.pdf) を引用。第 11 版 (2023/3) が現行
3. **Terraform**: HashiCorp 公式 (registry.terraform.io) + provider docs。バージョン明示
4. **不確定箇所**: 「未確定 (PoC 結果待ち)」「未確定 (PF 側ガイドライン提供待ち)」と明示。推測で埋めない
5. **金融庁ガイドライン**: 金融庁 (fsa.go.jp) のガイドラインを引用。出典 URL 必須

詳細は各文書末尾の「出典」セクションを参照。

## 変更時の影響範囲対応ルール (必読)

本パッケージ内の文書・図・コードは **ID 連鎖** (FR / NFR / ADR / R / ISS / EV) と **数値・固有名詞** で互いを参照しているため、**1 箇所を編集したら必ず影響先も同一コミット内で連動修正** する。

### 基本ルール
1. **編集前に grep**: `grep -rn '<変更対象の ID / 用語>' .` で影響範囲を可視化
2. **主変更 + 影響先を同一コミットで**: PR / コミット内で整合性が取れる単位に閉じる
3. **図を更新したら関連章本文の数値・固有名詞も確認**: 図と本文の齟齬は監査で即指摘される
4. **コミットメッセージに「影響範囲: <ファイル列挙>」を明記**: レビュアーが追跡しやすくなる
5. **ID をサイレントに変えない**: FR/NFR/ADR/R/ISS の ID 変更時はトレサ表まで全件追跡

### 代表的な連動パターン (詳細は `PM向け/09_変更影響範囲ルール.md`)

### 定期セルフチェック
- **週次**: 未確定事項管理表 Open 件数推移、リスク TOP 5 整合、図と本文整合
- **月次**: `grep -rn 'TODO\|要記入\|要数値\|要協議\|要確認' .` で未確定箇所棚卸、ADR 連動反映、出典 URL Dead Link チェック
- **フェーズ Exit 前**: Exit Criteria 全項目緑、ID 一意性、図と本文整合

## Codex 辛口レビュー gate

本リポジトリへの変更は、Claude Code の Stop hook 経由で **Codex (gpt-5.5) 辛口レビュー** が自動発火する設計 (`~/.claude/settings.json` Stop hooks の先頭に `stop-review-gate-hook.mjs` を登録、プロンプトは adversarial default 化、AWS Knowledge MCP / terraform-mcp-server で grounding 強制)。

- 編集ありのターン: adversarial 姿勢でレビュー → material findings あれば `BLOCK:` 出力で応答停止 → 修正 loop
- 編集なしのターン (status / summary のみ): `ALLOW:` で即抜け
- 詳細復元: `bash ~/.claude/scripts/restore-codex-review-mcp-grounding.sh` で plugin update 時に再注入可能
