# ANK-未割当-金融クーポン管理 (PM 参画準備パッケージ)

**案件**: 大手金融機関グループ向け 特別金利電子クーポン管理子システム (以降「本システム」) の要件定義〜総合テストまでの構築フェーズ一気通貫担当。  
**担当**: PM (兼 SA / コンサル相当) として、ヒアリングからパラメータ確定・Terraform/自動化による構築まで導く。  
**位置付け**: 親システム「顧客名寄せ親システム (全店名寄せ相当)」の子プロジェクト。次期クラウド共通基盤 (オープン勘定系 PF 相当) へリフト。  
**参画予定**: 2026 年 6 月 〜 2028 年 3 月 (構築フェーズ 22 ヶ月)、最大 4 名体制、出社地は東京都内オフィス。基本テレワーク。

> **本リポジトリの位置付け**: 本ローカル版はフル情報。GitHub 公開版は本リポジトリの `公開向け_マスキング/` 配下のみが対象 (機密マスキング処理済)。直接 push しない。

## 出典・引用ルール (ハルシネーション禁止)

本パッケージは金融機関規制対応資料として使用するため、以下の引用ルールを厳守する:

1. **AWS サービス仕様**: AWS 公式ドキュメント (docs.aws.amazon.com / aws.amazon.com/jp/blogs) を一次ソース。記述末尾に URL 必須
2. **FISC 安全対策基準**: FISC 公式 (fisc.or.jp) と AWS 公式リファレンス (d1.awsstatic.com/whitepapers/jp/security/AWS_FISC_Reference_Part_*.pdf) を引用。第 11 版 (2023/3) が現行
3. **Terraform**: HashiCorp 公式 (registry.terraform.io) + provider docs。バージョン明示
4. **不確定箇所**: 「未確定 (PoC 結果待ち)」「未確定 (PF 側ガイドライン提供待ち)」と明示。推測で埋めない
5. **金融庁ガイドライン**: 金融庁 (fsa.go.jp) のガイドラインを引用。出典 URL 必須

詳細は各文書末尾の「出典」セクションを参照。
