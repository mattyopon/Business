# ANK-未割当 - 新規案件用テンプレート

> **テンプレートの位置付けと使い方** (2026-05-14 追記)
>
> 本テンプレートは「AI / Kubernetes / Databricks を含むインフラ案件」向けに作られた参考実装です。**汎用 SES / コンサル案件にそのまま流用すると、AI / EKS / Databricks 前提が強く出すぎてしまう**ため、新規案件で利用する際は以下の手順で**案件特性に合わせて取捨選択**してください。
>
> **汎用テンプレとして流用する手順**:
> 1. 本フォルダをコピーして新案件番号にリネーム (例: `ANK0000XXXXXXX`)
> 2. `参画用/設計書.md`, `参画用/インフラ構成図.md`, `参画用/技術選定理由書.md` から **AI / MLOps / Databricks に固有の章** (`#### Databricks` `#### 機械学習` `#### MLOps Pipeline` 等) を**削除**するか、案件技術スタックに置換
> 3. `商談用/想定Q&A.md` の Q&A も同様に案件技術スタック (例: ECS / GKE / Azure / オンプレ等) に合わせて差し替え
> 4. `技術検証/` 配下のデモは、案件で実証すべき技術 (例: ECS Fargate, GitOps, データ基盤等) に応じて取捨選択
> 5. クライアント社名は記載せず `（非公開）` または `（サンプル企業名）` のままにすること
>
> **本テンプレが想定する案件特性**:
> - クラウドネイティブインフラ (AWS / GCP / Azure)
> - Kubernetes ベースのコンテナ運用
> - データ駆動アプリケーション (AI / 機械学習 / 分析基盤を含むケースが多い)
>
> **本テンプレが向かない案件**:
> - オンプレミス / VMware / ベアメタル中心の案件
> - SaaS 設定運用や Salesforce / Workday 等パッケージ運用中心の案件
> - フロントエンド / SPA / モバイル開発中心の案件
>
> 上記非対応案件では、本テンプレを丸ごとコピーせず、章立てだけ参考にして必要な章を新規作成してください。
