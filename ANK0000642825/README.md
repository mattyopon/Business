### 主な作業（想定）

- AWS環境における検索システムインフラの設計・構築
- OpenSearch/Elasticsearchクラスターの構築・チューニング
- 認証系（Cognito等）やAPI管理（API Gateway）の設計・構築
- コンテナ管理（ECS/EKS）によるアプリケーション基盤構築
- ネットワーク設計（VPC、サブネット、セキュリティグループ）
- ストレージ設計（S3、EBS、EFS）
