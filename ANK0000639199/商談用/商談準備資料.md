## 2. 経歴

### 【経験①】大手広告代理店 電車内広告配信システム（2023年8月〜2025年1月）

#### 概要
電車内広告動画配信システムのインフラ構築・運用を担当。

#### 技術スタック
- **AWS**: CloudFront, WAF, ALB, EC2, ECS, Aurora MySQL
- **コンテナ**: Docker, ECS + EC2
- **CI/CD**: GitHub Actions
- **動画処理**: Lambda + ffmpeg（4沿線対応）
- **セキュリティ**: GuardDuty, AWS Config, CloudTrail, Inspector

#### 担当業務
- CloudFront + WAF、ALB + EC2×2台によるWordPress冗長構成の設計・構築
- ECS + EC2（Docker コンテナ）基盤の構築
- Lambda + ffmpegによる動画変換パイプラインの実装
- GitHub Actionsを使用したCI/CDパイプラインの構築
- プライベートサブネット + SSM経由SSH設計
- クライアントセキュリティ基準対応、AWS Inspector脆弱性対応

#### 成果
- **コンテナ技術**: ECS + Dockerによるコンテナ基盤の設計・構築
- **CI/CD構築**: GitHub Actionsを使用した自動デプロイパイプライン構築
- **セキュリティ**: 企業セキュリティ基準に準拠したインフラ設計
- **動画処理**: サーバーレス（Lambda）を活用した動画変換パイプライン

### 【医療AI / MLOps / HPC への適合性 (本案件向け補足)】

直近2案件 (広告配信 / MSP 監視) は医療領域ではないが、本案件の中核要件は以下のように転用可能なスキルで対応する。

| 本案件の要件 | 既存実績からの転用 | 本リポジトリでの実施済み検証 |
|--------------|-------------------|----------------------------|
| AWS HIPAA 要件適合設計 (Eligible Services + BAA + 顧客側統制) | 広告配信案件で AWS Config / GuardDuty / IAM 最小権限 / 監査ログ整備の実装経験。クライアント側セキュリティ基準への適合実績あり | `参画用/運用ドキュメント/06_セキュリティガバナンス.md` で HIPAA 適用範囲 (海外PHI 取扱時の条件付き要件) と日本法 (個人情報保護法 / 要配慮個人情報) の責任分界を整理 |
| MLOps パイプライン (データ → 学習 → 推論 → 監視) | 広告配信案件で Lambda + ffmpeg のバッチ処理パイプラインを実装。データ駆動の運用感あり | `参画用/運用ドキュメント/02_MLOpsパイプライン設計書.md` で本案件向けの SageMaker / MLflow / モデル管理を文書化、`技術検証/mlops-pipeline-demo/` で雛形実装 |
| EKS Fargate ベースのコンテナ基盤 | 放送局 MSP では **ECS Fargate** の 24/365 監視運用経験あり (タスク監視 / 障害一次対応)。**EKS / Kubernetes の本番運用経験は無く、検証・学習レベル**。Pod 監視 / kubectl 操作は技術検証および公式ドキュメント・チュートリアルで習得中 | `技術検証/terraform-aws-infra/` で EKS 1.33 + Fargate Profile (default / application / mlops) を IaC 化（学習目的の検証実装）。本案件では Kubernetes 知見を有するチームメンバーと並走し、運用フェーズに入る前にキャッチアップを完了する想定 |
| HPC (GPU / AWS Batch / FSx) | GPU・HPC は商用本番運用は未経験 | `参画用/運用ドキュメント/07_HPC環境運用ガイド.md` で AWS Batch / GPU インスタンス (p4d / g5) / FSx for Lustre の設計を文書化。実機検証はチームと並走 |
| 24/365 SRE / Runbook | 放送局 MSP で 24/365 監視 + Runbook + エスカレーション設計の実績 | 既存運用感をそのまま転用 |

> 医療業界の **直接実績は本案件が初**となるが、AWS インフラ・SRE・IaC・コンテナ運用の地続きな延長として、設計判断と運用整備にコミットする。GPU / HPC / HIPAA の細部はチームリードと並走しつつ、必要な認定・知識を本案件期間中に取得する計画。

### 【経験②】大手放送局グループ MSP監視運用（2024年1月〜2025年6月）

#### 概要
大手放送局グループの複数サービスに対する24/365監視運用代行を担当。

#### 技術スタック
- **AWS**: ECS Fargate, RDS, ElastiCache, ELB
- **CDN/WAF**: Fastly CDN + WAF
- **監視**: New Relic APM/Infrastructure, Zabbix
- **その他**: GCP

#### 担当業務
- New Relicによる監視設計・アラート設定
- Runbook作成（障害対応フロー）
- Fastly WAF運用（ブラックリスト管理、セキュリティレポート）
- AWS IAMポリシー設計（スイッチロール、最小権限）
- 障害一次対応フロー設計・エスカレーションルール策定
- 24/365監視運用

#### 監視対象
ECS Fargate, Fastly CDN, RDS, ElastiCache等

#### 成果
- **SRE実践**: 24/365監視運用、Runbook整備、インシデント対応フロー設計
- **監視基盤**: New Relic APM/Infrastructureを使用した監視設計
- **コンテナ運用**: ECS Fargateの運用経験
- **セキュリティ**: WAF運用、IAM最小権限設計
